01 — Overview

What is APEX AI?

APEX stands for AI Powered Masters Program Explorer. It is a full-stack, intelligent educational consultant application that acts as a personalized academic advisor. Through natural conversation, it extracts three critical preferences from a student — their Domain of Interest, Preferred Countries, and Tuition Fee Budget — then generates highly curated program recommendations, learning roadmaps, and motivational summaries.

APEX simulates an agentic workflow: it listens, understands when it has gathered enough context, and sequentially triggers specialized AI chains to deliver deep, structured insights — all rendered beautifully in the frontend using Markdown formatting.

🎯

Personalized Discovery

Extracts Domain, Country, and Budget through natural conversation, then curates the top 5 Master's programs scored on Reputation, Research, Industry Exposure, and Employability.

🗺️

Learning Roadmaps

Generates structured domain-specific learning paths covering Foundations, Core Concepts, Tools, Advanced Topics, Projects, Research, and Career Prep.

✨

Inspiring Summaries

Synthesizes program recommendations and roadmap data into a cohesive, motivational final overview designed to inspire and guide the student's next steps.

Key Workflow at a Glance

The user opens the app → interacts in chat → the AI extracts structured data → once all 3 preferences are confirmed, three specialized chains trigger sequentially to produce programs, a roadmap, and a summary — all rendered as rich Markdown in the chat interface.
02 — Architecture

System Architecture

APEX is built as a two-tier system: a React frontend that communicates with a FastAPI backend via HTTP, and the backend orchestrates multiple LangChain chains powered by Google Gemini.

⇅ LangChain Orchestration — Prompt → LLM → Parser
AI LAYER
LangChain (LCEL) Google Gemini 2.5 Flash PromptTemplate StrOutputParser JsonOutputParser workflow.py

Communication Pattern

REQUEST
Frontend sends JSON payloads (conversation history, extracted fields) to FastAPI endpoints.
PROCESS
LangChain chains execute: format prompt → call Gemini → parse output (JSON or Markdown).
RESPONSE
Backend returns structured JSON (reply + extracted fields) or Markdown strings to the frontend.

06 — Core Concepts

Core Concepts Used

APEX implements several important AI engineering patterns that make it both intelligent and efficient.

01
Prompt Engineering

Structured Output via JSON in Prompts

The AI is explicitly instructed through the chat_extraction_template to return both a conversational reply AND a structured JSON object. This dual-output pattern lets the system extract machine-readable data (Domain, Country, Budget) while maintaining a natural conversation flow.

02
Chaining

Chained LLM Operations (LCEL Pipelines)

LangChain Expression Language (LCEL) composes chains as prompt | llm | output_parser. The Top Programs chain uses a 2-step chain: first generate, then refine. This modular design makes each step replaceable and testable independently.

03
State Management

Frontend State Transitions

The React frontend manages distinct application states (loading → landing → home) using React hooks, without needing Redux. The extraction state is also tracked locally, detecting when all three fields are filled to trigger the workflow cascade.

04
Agentic Simulation

Simulated Agentic Workflow

While APEX doesn't use external retrieval (RAG), it simulates an agentic loop: it perceives (extracts fields), reasons (detects completeness), and acts (triggers specialized endpoints). This mirrors the Plan-Act-Observe loop of true agents.

05
Output Refinement

Two-Pass LLM Refinement

The Top Programs chain uses a two-pass approach: the first LLM call generates content, and the second pass (via output_refinement_template) polishes and restructures the Markdown. This quality-control pattern ensures consistently formatted, professional output.

06
Parametric Knowledge

LLM as a Knowledge Base

APEX relies purely on Gemini's internal parametric knowledge to act as a consultant — no external databases or RAG pipelines. This simplifies architecture while still delivering accurate, up-to-date program recommendations based on the model's training data.

08 — API Endpoints

API Endpoints Reference

All endpoints are defined in backend/routes/api.py and registered in backend/main.py. The FastAPI server runs on localhost:8000 by default.

POST /api/chat

The primary conversational endpoint. Processes user messages, generates a reply, and extracts structured preference data.

Chainextract_chat_info
Input{ history: [], message: string }
Output{ reply: string, domain: str|null, country: str|null, budget: str|null }
POST /api/top-programs

Generates the top 5 Master's program recommendations, scored and formatted as rich Markdown.

Chaingenerate_top_programs
Input{ domain: str, country: str, budget: str }
Output{ programs: markdown_string }
POST /api/generate-roadmap

Generates a structured 7-category learning roadmap tailored specifically to the user's domain of interest.

Chaingenerate_roadmap
Input{ domain: str }
Output{ roadmap: markdown_string }
POST /api/summary

Synthesizes the program list and roadmap into a cohesive, motivational final summary for the student.

Chaingenerate_summary
Input{ programs: str, roadmap: str }
Output{ summary: markdown_string }
